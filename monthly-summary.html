Monthly Summary

All activity types use the activity date, including both the start and end dates. Archived activities are included so previous cycles remain available. Event totals reflect the recorded application, selection, and final status.

Interaction cards and Excel scores use the selected evaluation month. It defaults to the end date's month when you change the activity range; you can choose another month.
